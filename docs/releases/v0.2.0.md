# Job Harness 0.2.0

Your career workspace. Any capable agent.

The native Rust preview brings sourced answers, searchable career context, exact application packets and interrupted-work recovery into one private workspace. Drive it through CLI or MCP, launch an external ACP agent, or choose a compatible local/remote model host.

## Choose your component

- **`job-harness`**: native core, `jh` alias, embedded contracts/skills, exact search, notes, application coordination, backups and local dashboard. No model, Python, Rust compiler or VM is required by the installed binary.
- **`job-harness-local`**: optional native model provider. Runtime libraries and weights are separate, explicitly reviewed downloads; neither is included in this software archive.
- **`job-harness-desktop`**: optional native window using the same local engine and review boundaries, with a macOS app bundle or Windows/Linux executable. Opens the configured workspace or an existing-folder chooser. Requires the platform webview; no second tracker or cloud account.

Choose the archive matching your OS/CPU. Validate its exact SHA256 against `SHA256SUMS`. Each archive includes a license, component installation instructions and `BUILD.json` with source/target identity. Preview binaries are unsigned.

## First run

```sh
jh setup --workspace "$HOME/Career/workspace"
jh status
jh connect mcp
```

Setup shows optional capabilities and their requirements without installing them. `--plan --json` is a no-write plan for agents. `jh demo --workspace PATH` creates a searchable fictional workspace for evaluation.

## What changed

- Shared native engine and official SDK transports; compact versioned envelopes, focused/full discovery and chained batches.
- Source-preserving note intake, selective cited review and stable context packs.
- Derived SQLite exact search, optional semantic retrieval and bounded typed suggestions; model outputs do not become facts.
- Existing primary PDFs, evidence-linked Typst CVs and selected document exports.
- Portable private bundles preserve exact artifacts and unresolved attempts; no candidate profile is part of this repository.
- Board-first native controls, direct guarded drag moves, counted attention, focused note review and responsive panels.
- Local change notifications reflect CLI/agent writes without repeated scans; unsaved work defers refresh.
- Actual device checks, copyable MCP configuration and explicitly reviewed Gemma/Laya downloads keep setup concrete.
- Native development/privacy/resource gates and component-aware release packaging; historical migration vectors remain after retiring Python source.

## Important boundaries

The engine records one attempt and checked outcome evidence; it does not guarantee exactly-once delivery at an employer. Browser, mail and calendar actions remain in your chosen host and current user scope. Model/runtime hardware support and measured checks are documented separately. Cross-platform builds do not establish GUI runtime acceptance on every OS or live employer/provider correctness.

Private workspace bundles are plaintext ZIPs. Encrypt separately before sharing. Keep credentials in the host's secure store. This release remains private and does not publish a Cargo/npm/Homebrew package or enable hosting.

See the installation, architecture, model and contributing guides in the repository.
